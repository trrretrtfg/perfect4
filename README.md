# ذِكرى (ZIKRA) — نسخة متوافقة مع مشروع Supabase الحالي

هذه النسخة مبنية على مشروع Supabase الحالي ذي المعرّف `zmssushpynpsrlkswltf`. **لا تنشئ قاعدة بيانات جديدة، ولا تنفّذ ملف `supabase/schema.sql`**؛ الملف محفوظ كمرجع تاريخي فقط، وهو ليس مخطط قاعدة البيانات الفعلية المستخدمة حالياً.

## التقنية

- Expo SDK 51
- React Native 0.74.5
- React 18.2.0
- Expo Router 3.5
- Supabase JS 2.x
- Zustand 4.x
- ThmanyahSans (Black / Medium / Light)

## إعداد الاتصال

بيانات الاتصال العامة موجودة في `src/constants/config.js`، وتهيئة العميل في `src/lib/supabase.js`.

- يستخدم التطبيق عنوان مشروع Supabase الحالي ومفتاح Publishable العام.
- لا يوجد `service_role` أو أي سر إداري داخل التطبيق.
- جلسات الدخول تأتي من Supabase Auth وتُحفظ محلياً مع refresh token، مع تجديد الجلسة تلقائياً.

## تكامل التطبيق مع الخدمات الحالية

| الوظيفة | المصدر الفعلي |
|---|---|
| تسجيل الدخول وإنشاء الحساب باسم المستخدم | Edge Function: `zikra-username-auth` |
| إنشاء الغرف وطلبات الانضمام وإدارتها | Edge Function: `zikra-room-api` |
| الملفات الشخصية والغرف والذكريات والتفاعلات والتعليقات والإشعارات | جداول `public` الحالية عبر Supabase Auth وRLS |
| Chat Room داخل صفحة الغرفة | جدول `public.room_chat_messages` مع Realtime وRLS للأعضاء النشطين فقط |
| إشعارات الرسائل | Trigger في قاعدة البيانات: أول رسالة، ثم بعد انقطاع يتجاوز 7 دقائق، مع استثناء المرسل |
| إشعارات الذكريات الجديدة | Trigger يرسل إلى الأعضاء النشطين باستثناء صاحب الذكرى |
| إشعارات الإعجاب والتعليق | Trigger يرسل لصاحب الذكرى حتى إذا كان هو نفسه صاحب التفاعل |
| قراءة التعليقات مع حماية هوية التعليقات المجهولة | View: `public.memory_comments_visible` |
| توقيع رفع الصور | Edge Function: `zikra-cloudinary-sign-upload` |
| التحقق من الصور وتسجيل بياناتها | Edge Function: `zikra-cloudinary-register-media` |
| تسليم الصور الخاصة بروابط مؤقتة | Edge Function: `zikra-cloudinary-deliver-media` |
| تخزين الصور | Cloudinary الخاص، وليس Supabase Storage |

لا يستخدم التطبيق دوال RPC القديمة أو جداول `app_users` و`app_sessions` أو وظيفة `zikra-media` القديمة.

## Chat Room والإشعارات

- المحادثة متاحة من داخل صفحة الغرفة، ولا يوجد لها عنصر في الـ Bottom Bar.
- كل عضو نشط في الغرفة يستطيع قراءة الرسائل وإرسالها تلقائياً؛ إزالة العضو من الغرفة تمنع وصوله إلى المحادثة عبر RLS.
- الرسائل نصية حالياً، ويصل التحديث المباشر عبر Supabase Realtime.
- أول رسالة في الغرفة تنشئ إشعاراً للأعضاء الآخرين. بعد ذلك لا ينشأ إشعار جديد إلا إذا تجاوز الفاصل بين الرسالة الحالية والسابقة 7 دقائق.
- إشعارات المحادثة تستثني مرسل الرسالة، وإشعارات الذكرى الجديدة تستثني الناشر. إشعارات الإعجاب والتعليق تصل لصاحب الذكرى دون استثناء.
- الضغط على إشعار المحادثة يفتح تبويب المحادثة ويحدد الرسالة المقصودة.
- جميع الإشعارات داخل التطبيق فقط؛ لا تُستخدم Push Notifications.

## التصميم

- الوضع الفاتح هو الافتراضي.
- الصفحة الرئيسية تعرض شبكة الصور دون بطاقات معلومات إضافية.
- فتح الذكرى يعرض الصورة بنسبة أبعادها دون قص (`contain`).
- فقاعة «التفاصيل» الزجاجية البيضاء تظهر أعلى الصورة، ولا تُفتح التفاصيل إلا عند الضغط عليها.
- لا توجد إشعارات Push؛ الإشعارات داخل التطبيق فقط.

## إعدادات البناء

`app.json` ما زال يحتفظ بمعرّف Android وiOS الموجود في النسخة المرسلة. لا تغيّره إلا إذا أردت اعتماد معرّف تطبيق جديد، لأن تغييره ينتج هوية تثبيت مختلفة على الهاتف.

## حدود التوافق المعروفة

بعض العمليات القديمة غير موجودة في واجهة الخادم الحالية، لذلك أُزيلت أزرار مغادرة الغرفة وإعادة توليد رمز الدعوة بدلاً من عرض أزرار لا تعمل. رمز الغرفة يُعرض مرة واحدة عند إنشائها؛ احتفظ به لمشاركته.

## حماية قاعدة البيانات

هذا المشروع لا يحتوي على خطوة تثبيت أو ترحيل تلقائي لقاعدة البيانات. لا تشغّل ملف `supabase/schema.sql` على مشروع Supabase الحالي؛ فهو مرجع تاريخي وليس المخطط الحي. تم نشر تغييرات Chat Room والإشعارات على مشروع Supabase الحالي عبر migrations مستقلة والتحقق منها باختبارات معاملات مؤقتة تم التراجع عنها.


## خطوط الواجهة
قبل إنشاء نسخة Android/iOS، ضع ملفات الخطوط داخل `assets/fonts/` بالأسماء الدقيقة التالية: `thmanyahsans-Black.ttf` و`thmanyahsans-Medium.ttf` و`thmanyahsans-Light.ttf`. تم إعداد `expo-font` لتحميل هذه الملفات قبل إظهار واجهة التطبيق. العناوين تستخدم Black، النصوص الاعتيادية Medium، والنصوص الصغيرة Light.

## ربط Telegram (اختياري)

- من صفحة «حسابي» يستطيع المستخدم ربط حساب Telegram أو فصله.
- بعد الضغط على «ربط حساب Telegram» يفتح رابط البوت؛ يجب الضغط على Start لإكمال الربط لأول مرة.
- Telegram قناة إضافية لإيصال إشعارات مختصرة فقط، ولا يُستخدم لتسجيل الدخول أو لعرض سجل الإشعارات أو التفاعل معها.
- الإشعارات الداخلية في ذِكرى تبقى المصدر الأساسي ولا تتكرر عند إرسال نسخة Telegram.
- لا تُرسل تفاصيل الذكريات أو نصوص التعليقات أو رسائل الغرف إلى Telegram.
- يتولى Supabase Edge Function `zikra-telegram` إنشاء رموز الربط المؤقتة والتحقق من Webhook وإرسال الإشعارات، ويعمل مجدول الإرسال كل دقيقة مع إعادة المحاولة المنضبطة.
- يجب أن يكون السر `TELEGRAM_BOT_TOKEN` مضبوطاً في Supabase Edge Function Secrets؛ لا تضفه إلى التطبيق أو ملفات ZIP أو المستودع.
